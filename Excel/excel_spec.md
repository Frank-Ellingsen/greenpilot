Markdown Prompts til Microsoft 365 Copilot i ExcelKopier og lim disse direkte inn i Copilot-sidepanelet i Excel for å automatisere oppsettet:Prompt 1: Etablering av KPI-blokkenDu er en senior finansiell modellør for Elkem.
I det aktive arket '01_Overview', sett opp 6 formaterte KPI-kort i området B6:G8:

1. BAC: Formel =SUM(tbl_WBS[bac_nok])/1000000, format '#,##0.00 "MNOK"'.
2. Actual Cost: Formel =XLOOKUP($I$2, tbl_Timeline[period], tbl_Timeline[ac_cum_nok])/1000000.
3. Earned Value: Formel =XLOOKUP($I$2, tbl_Timeline[period], tbl_Timeline[ev_cum_nok])/1000000.
4. Cost Variance: Formel =D8-C8, format '+#,##0.00 "MNOK";-#,##0.00 "MNOK";0.00 "MNOK"'.
5. CPI: Formel =IF(C8>0, D8/C8, 0), format '0.00'.
6. Open Commitments: Formel =SUM(tbl_TopPO[open_commitment_nok])/1000000, format '#,##0.00 "MNOK"'.
